# Release notes

## 0.3.2 - source release

- Separate Inference Server and RPC Node workspaces with service controls and connection instructions.
- Embedded llama.cpp chat interface with native-style branding, model management and API-key integration.
- RPC memory, transfer, graph, CPU, GPU-command timing, power and thermal-pressure monitoring.
- Adaptive device defaults for Apple M-series iPads, with foreground lifecycle handling and memory-aware worker allocation.
- Matching Mac coordinator launcher with layer placement, memory controls and optional speculative decoding.
- Retained engine integrations for RPC lifecycle, telemetry, optional Metal tuning/fusions and canonical LFM2MoE speculative replay.
- Vendored pinned source, consolidated engine patch, build/signing guides and integrity manifests for source-archive builds.

This package includes no test suites, model weights, signed binaries, personal machine records or private benchmark data. It is a development release; provisioning, model compatibility and performance depend on the target device and configuration.
